# Naming

## Project Name

Display name: `KyberM0nk`

Repository name: `kyberm0nk`

## Rationale

The name combines:

- `Kyber`: sharp, technical, secure, sci-fi adjacent.
- `M0nk`: personal namespace linked to `m0nklabs` and the operator identity.

GitHub searches on 2026-05-06 showed no public repository collisions for:

- `kyberm0nk`
- `kybermonk`
- `kyber-m0nk`
- `kyber-monk`

## Rejected Names

- `Nexus`: too generic and crowded.
- `Nexus Forge`: already used by multiple repositories, including established projects.
- `Agent Nexus`: already used in the AI agent space.
- `Aether`: heavily used, including AI agent projects.
- `AetherForge`: already used, including agent-builder style projects.
- `Kyber`: heavily associated with post-quantum cryptography and KyberSwap.
